## UI Updates

The `ui-updates` branch contains the latest accessibility and user-interface improvements for the medication scanner.

### Accessibility Features

- **Large Text** — increases text size throughout the application.
- **High Contrast** — provides stronger borders, darker backgrounds, and brighter text for improved visibility.
- **Voice Guidance** — provides optional spoken feedback for important scanning events.
- **Haptic Feedback** — provides vibration feedback during scanning and interaction.
- **Screen Reader Support** — supports VoiceOver on iOS and TalkBack on Android through Flutter Semantics.
- **Large Touch Targets** — buttons and interactive elements are designed for easier interaction.
- **Clear Scanner Feedback** — provides visual and haptic guidance to help users position medication labels correctly.

### UI/UX Improvements

The updated interface focuses on accessibility, clarity, and ease of use. The scanner provides clear status messages, positioning feedback, accessible controls, and confirmation dialogs for potentially duplicate medication scans.

The `ui-updates` branch is currently used for development and testing of these improvements.
